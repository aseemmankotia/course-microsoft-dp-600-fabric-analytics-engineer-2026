# Chapter 8 Lab: Real-Time Intelligence: KQL for Streaming Data

**Estimated time:** 15 minutes

## Exercise

Walkthrough: configure an Eventstream to ingest sample telemetry events into a KQL database, then explain a sample KQL query using where, summarize, and project

## Key takeaway

Real-Time Intelligence with Eventstream and KQL databases is the correct choice for streaming/time-series data, distinct from batch lakehouse or warehouse ingestion.
