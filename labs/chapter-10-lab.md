# Chapter 10 Lab: Semantic Model Storage Modes: Direct Lake, Import, DirectQuery

**Estimated time:** 20 minutes

## Exercise

Walkthrough: create a Direct Lake semantic model directly from a lakehouse, then compare its behavior and refresh needs against an equivalent Import mode model

## Key takeaway

Direct Lake avoids duplication but can silently fall back to DirectQuery-like performance, while Import mode trades refresh scheduling for the fastest query speed.
