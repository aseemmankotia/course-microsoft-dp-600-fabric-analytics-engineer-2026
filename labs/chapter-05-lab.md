# Chapter 5 Lab: Lakehouse vs Warehouse: Choosing the Right Storage Item

**Estimated time:** 20 minutes

## Exercise

Walkthrough: create a lakehouse and load sample data via notebook, then create a warehouse and write T-SQL CREATE TABLE statements, comparing the read-only SQL analytics endpoint against the writable warehouse endpoint

## Key takeaway

Choose lakehouse for flexible Spark-driven storage and warehouse for governed T-SQL workloads; both sit on OneLake but expose data differently.
