# Chapter 4 Lab: Ingestion Foundations: Dataflows Gen2, Pipelines & OneLake Shortcuts

**Estimated time:** 20 minutes

## Exercise

Walkthrough: build a Dataflow Gen2 that loads a CSV into a lakehouse table, create a pipeline with a Copy activity, and create a OneLake shortcut to an external ADLS container

## Key takeaway

Dataflow Gen2 transforms, pipelines orchestrate, and shortcuts reference data without copying it — the exam tests picking the right one per scenario.
