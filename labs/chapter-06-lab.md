# Chapter 6 Lab: Transforming Data with Notebooks and PySpark

**Estimated time:** 25 minutes

## Exercise

Walkthrough: read a CSV into a PySpark DataFrame, apply transformations (filter, groupBy, join), and write the result to a Delta table, explaining each key line rather than reading code line by line

## Key takeaway

Notebooks provide the heaviest, most flexible transformation power in Fabric, but require a properly attached lakehouse to resolve table references.
