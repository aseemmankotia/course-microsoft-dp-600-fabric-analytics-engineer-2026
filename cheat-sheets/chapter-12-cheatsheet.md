## Chapter 12 Cheat Sheet: 100-Minute Pacing & Final Review

### Exam Item Budget
| Item Type | Count | Time Budget | Notes |
|---|---|---|---|
| Standalone | ~48 | ~1 min each (~48 min) | Flag and move on if over ~90 sec |
| Case-study | ~11 | ~52 min total for set | Read scenario once; reference exhibits per-question |
| Final review buffer | — | 5-10 min | Reserved strictly for flagged items |

### Domain Weights (use for review prioritization)
| Domain | Weight |
|---|---|
| Maintain a data analytics solution | 25-30% |
| Prepare and serve data | 45-50% |
| Implement and manage semantic models | 25-30% |

Rule: when time is short, review flagged items in the highest-weighted domain first.

### Case-Study Strategy
1. Read the full scenario and exhibits ONE time.
2. Answer all questions tied to that case together, in sequence.
3. For each question, open ONLY the specific exhibit/tab it references — do not re-read the whole scenario.
4. Flag anything uncertain; do not stall the set.

### Standalone Strategy
- Budget ~1 minute per item.
- If undecided after eliminating obviously wrong options, pick best guess, flag, move on.
- Never leave an item blank.

### Elimination Strategy
| Wording Signal | Meaning | Action |
|---|---|---|
| "which ONE / single solution" | Standard single-answer | Eliminate constraint-violating & deprecated-service options first |
| "which combination is the BEST" | Still single-answer | Correct option bundles multiple actions into ONE choice — do not select multiple options |
| Deprecated/legacy service named | Distractor | Eliminate immediately |
| Doesn't meet ALL stated constraints | Distractor | Eliminate immediately |

### Final Review Checklist (in priority order)
1. Flagged items in **Prepare and serve data** (highest weight — review first).
2. Flagged items in **Maintain a data analytics solution**.
3. Flagged items in **Implement and manage semantic models**.
4. Confirm no item was left blank.
5. Confirm no multi-select misinterpretation on "combination"-worded items.
6. Submit once buffer time is exhausted or all flags reviewed.
